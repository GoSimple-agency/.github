# Getting help

Pick the channel that matches what you need.

| You need | Go to |
| --- | --- |
| How to integrate, which call to use, best practice | [Discussions → Q&A](https://github.com/orgs/GoSimple-agency/discussions) |
| A bug in an SDK (wrong request, crash, wrong type) | An issue in that SDK's repository |
| Your account, billing, an API key, or a specific receipt | **info@gosimple.agency** |
| A security vulnerability | [SECURITY.md](./SECURITY.md), never in public |

Product documentation lives at
[tezgafiskal.com/en/fiscalization-api](https://tezgafiskal.com/en/fiscalization-api), and the
API contract at [tezgafiskal.com/api/openapi.json](https://tezgafiskal.com/api/openapi.json).

## Never post in public

Issues and Discussions are public and indexed by search engines. Do not post:

- an **API key** (`tzg_…`) or a webhook secret, even a sandbox one;
- a real buyer's **PIB**, name, email or address;
- a full receipt, PDF or verification link that belongs to a real customer.

Reproduce the problem with made-up data, or email us. A key that ends up in public should be
revoked in Settings → Integrations right away.
